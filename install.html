Aiden Agent

从下载安装到直接输入命令启动

本指南面向第一次使用的用户，介绍如何在 Windows 上安装、配置和运行 Aiden Agent。

安全提醒： Agent 会把经过处理的用户请求和必要的工具结果发送到配置的模型服务。请使用你自己的 API Key，并不要输入未脱敏的密码、私钥或业务机密。

一、准备环境

Python

安装 Python 3.11 或更高版本，并在安装时勾选 Add Python to PATH。

Git

用于从 GitHub 获取项目代码。也可以下载 ZIP 压缩包，但 Git 更方便升级。

模型 API

准备一个兼容的模型服务 API Key，例如 DeepSeek 或其他 OpenAI 兼容服务。

二、安装 Agent

1
安装 pipx

pipx 会为命令行工具创建独立环境，不会污染系统 Python。

python -m pip install --user pipx
python -m pipx ensurepath
2
重新打开 PowerShell

让刚加入 PATH 的 pipx 命令生效。

3
从 GitHub 安装 
pipx install https://github.com/zhaoge-99/liuzhengzheng-agent.git

三、配置项目环境变量

使用 pipx 安装时，Agent 的 Python 虚拟环境默认位于 C:\Users\<用户名>\AppData\Local\pipx\pipx\venvs\ 下。请把配置文件放在用户目录，而不要修改 pipx 虚拟环境中的文件。

提示：pipx 只负责下载并安装 Python 包，不会自动创建或配置 aiden_env，因此需要用户手动创建并配置该文件。

以下两种方法都使用 GitHub 上的 aiden_env.example 配置模板。请将模板内容复制到 C:\Users\<用户名>\aiden_env，并把 <用户名> 替换为你的 Windows 用户名。文件名必须是 aiden_env，不要保存成 aiden_env.txt。

程序会从当前工作目录读取 aiden_env。因此，请在用户目录打开 PowerShell 并从该目录运行 aiden。

MODEL_PROVIDER 可选值： openai-compatible 用于 DeepSeek、OpenAI 以及其他兼容 OpenAI API 的服务； anthropic 用于 Anthropic Claude； gemini 用于 Google Gemini。 选择的 Provider 必须与对应的 API 地址和模型名称匹配。

方法一：设置 Windows 用户环境变量

先将命令中的提示文字替换为服务商提供的实际配置，再在 PowerShell 中执行，将四项模型服务配置保存为 Windows 用户环境变量：

[Environment]::SetEnvironmentVariable("MODEL_PROVIDER", "填写服务商标识（openai-compatible、anthropic 或 gemini）", "User")
[Environment]::SetEnvironmentVariable("MODEL_API_KEY", "你的API Key", "User")
[Environment]::SetEnvironmentVariable("MODEL_NAME", "填写服务商提供的模型名称", "User")
[Environment]::SetEnvironmentVariable("MODEL_BASE_URL", "填写服务商提供的 API 地址", "User")

将模板内容复制到 aiden_env 后，前四个模型变量可以留空，因为它们已在 Windows 用户环境变量中配置。其他需要的选项（例如 AGENT_WORKSPACE）可在此文件中设置。今后如需更改模型服务的这四项配置，请修改 Windows 用户环境变量；更改后关闭并重新打开 PowerShell，再重新启动 Agent 才会生效。

方法二：只使用 aiden_env 文件

如果不想设置 Windows 用户环境变量，就把以下全部配置写入 aiden_env。将每项提示文字替换为实际值后再保存；前四项是模型服务配置，其余是工作区和运行限制配置：

MODEL_PROVIDER=填写服务商标识（openai-compatible、anthropic 或 gemini）
MODEL_API_KEY=填写你自己的模型 API Key
MODEL_NAME=填写服务商提供的模型名称
MODEL_BASE_URL=填写服务商提供的 API 地址
AGENT_WORKSPACE=填写工作区的绝对路径
AGENT_MAX_ITERATIONS=填写最大模型与工具往返次数（1-30）
AGENT_REQUEST_TIMEOUT=填写模型请求超时秒数（5-120）
AGENT_MAX_CONCURRENT=填写最大并发工作流数量（正整数）
AGENT_QUEUE_TIMEOUT=填写等待并发槽位的最长秒数（可为0）

注意：已设置的 Windows 用户环境变量优先于 aiden_env，同名配置不会被文件覆盖。若要使用方法二，请先从 Windows 用户环境变量中删除之前设置的同名模型变量。真实的 aiden_env 可能包含 API Key，不要提交到 Git 或分享给他人。

四、启动和第一次对话

aiden

看到启动提示后，直接输入问题，例如：

你好，请介绍一下 Python 的环境变量

退出程序：输入 /q、/quit 或按 Ctrl+C。

五、常用命令

/help

显示帮助信息。

/workspace

查看当前工作区。

/status

查看 Agent 状态。

/tasks

查看未完成任务。

/clear

清空当前对话。

/q

退出 Agent。

六、让 Agent 修改代码

  1. 描述要修改的文件和目标。
  2. Agent 先生成补丁并预览变更。
  3. Agent 校验补丁，等待你在终端确认。
  4. 确认后才会应用修改。
  5. 应用后自动进行语法检查和质量验证。
  6. 验证失败时会报告原因，并尝试回滚补丁。

不要把工具参数中的 confirm=true 当作用户授权；真正的写操作必须经过终端确认。

七、升级、卸载和故障排查

升级到 GitHub 最新版本

pipx upgrade aiden-agent

卸载

pipx uninstall aiden-agent

常见问题

  • 提示未配置 API Key：关闭终端后重新打开，确认变量名是 MODEL_API_KEY。
  • 网络连接失败：检查 MODEL_BASE_URL、代理和模型服务是否可访问。
  • 模型不存在：把 MODEL_NAME 改为服务商账户实际支持的模型名称。
  • 命令找不到：重新运行 python -m pipx ensurepath 并重启终端。
